"# WAFCAgame"  

enchant.jsを使用して作成した、ブラウザで遊べる2Dトップダウン型のアクションゲームです。
迫りくる障害物を避けながらアイテムを集め、制限時間内に高得点を取ることを目指します。

##  あそびかた 

### 操作方法
*   **矢印キー (↑ ↓ ← →)** : プレイヤーの移動
*   **クリック** : 画面の進行（言語選択、スタート、リスタート）

### ルール
*   画面上部から迫ってくる障害物（空き缶、石、道路の亀裂など）を避けて進みます。
*   障害物に当たるとライフが1減ります。**ライフが0になる**とゲームオーバーです。
*   制限時間（15秒）の間、**ライフを残したまま生き残る**ことができればゲームクリアです！

### アイテム
道を走っていると、以下のアイテムが落ちてくることがあります。
*   **スピードアップ ![スピード](./speed.png)** : プレイヤーの移動速度が1段階上がり（最大レベル5）、スコアが+500されます。
*   **ライフ回復 ![ライフ](./life.png)** : ライフが1回復し（最大5）、スコアが+500されます。

## 特徴
*   **多言語対応** : ゲーム開始時に日本語（JAPANESE）と英語（ENGLISH）を選択できます。
*   **多様な障害物** : まっすぐ落ちてくるもの、横にスライドするもの、揺れながら落ちてくるものなど、動きの異なる複数の障害物が登場します。
*   **ドネーションリンク** : ゲームクリア/ゲームオーバー後のリザルト画面から、寄付ページ（WAFCA）へのリンクへアクセスできます。

## 開発環境 / 使用技術
*   HTML5 / JavaScript
*   [enchant.js](https://github.com/wise9/enchant.js/) (ゲームエンジン)

##  実行方法 
ダウンロードしてindex.htmlを実行するとプレイできます
